# ADR 0003：以原文字面锚点选择当前 Surface 压缩区间

- 状态：Accepted（已采纳）

## 背景

主动压缩由当前工作模型选择已处理的历史并撰写摘要，宿主验证后替换完整节点区间。先取得地图、再引用 `snapshot_ref` 和 seq/edge 的协议，要求模型为定位承担额外工具回合、地图字段和预览成本。模型已掌握独特原文时，可以直接用原文表达区间边界。

本 ADR 取代 [session-tools ADR 0004](<../../../dsh-session-tools/docs/adr/0004-context-map-and-metering.md>) 的模型地图设计，以及 [ACP ADR 0001](<0001-active-compaction-submission.md>) 的地图字段、取图与 freshness 协议和 [ACP ADR 0002](<0002-pressure-notices.md>) 的粗地图提醒设计。提交生命周期、保护、原生事务、计量和提醒去重继续遵循原 ADR；冲突处以本 ADR 为准。

## 决策

### 模型直接提交两个原文端点

取消模型工具 `session_context_map`，取消以地图取得 `snapshot_ref` 和 seq/edge 作为压缩必经流程。map-specific 公共库和 API 随其消费者一并移除；底层 Query `captureSession`、tokenMeter 和现有 session/event read、search、trace 工具保留。

`context_compress` 只操作当前调用会话。每个区间直接给出两个 literal 短原文端点和模型撰写的非空 `summary`。接口采用 `range` 的两个 endpoint，各含 `text` 和可选 `role`；`role` 复用派生消息的 actual role 枚举，不新增来源、活动或工具名称选择器。字段命名在接口收敛时与全部消费者同步，语义以本 ADR 为准。

下列仅为接口示意，不是会话记录：

```json
{
  "regions": [
    {
      "range": [
        { "text": "先核对输入数据的来源", "role": "user" },
        { "text": "来源核对结束，保留两项未解决约束", "role": "assistant" }
      ],
      "summary": "保留核对结论、精确名称与路径、两项未解决约束及必要回读入口。"
    }
  ]
}
```

第一个端点定位起始节点，第二个端点定位结束节点；区间包含两端的完整节点及其中间全部节点。两个端点可以定位同一节点。顺序按当前 Surface 位置解释，不按内部 seq 数值排序。不提供 `edge`，也不在节点内部执行字符级替换。

### 字面匹配与唯一性

匹配对象仅为当前 Session 的 `deriveEventMessage` 所得消息的 **text block 原文**，包括工具结果的 text block。每个 block 独立做大小写敏感的 literal substring 匹配，不 trim、不做空白或 Unicode 规范化。关键词也是普通字面子串，不是 FTS 查询或语法表达式；端点必须非空。

不匹配 reasoning、工具参数 JSON、地图合成预览、附件占位、provider 后加的 wrapper 或原始 Log；不把相邻 block 或节点拼接为可跨界匹配的文本。这一 basis 是当前派生消息正文，不承诺等同于任一路由最终 wire 文本或模型过去逐字见过的内容。

两个端点分别在整个当前 Surface 中匹配；有 `role` 时仅限定该端点的候选节点，不过滤区间内部的其他角色。唯一性按**匹配节点数**计算：同一节点内同一 block 的多次命中、多个 block 的命中均合并为一个节点。原文在不同节点重复出现，即使是源码或引用，也算多个候选。结束端点不能默取起始端点之后的第一个匹配。

任一端点无匹配或匹配多个节点，整体预检拒绝全批，不执行任何替换。诊断指出问题端点，并提供有界原文线索和必要的 role，供模型换更独特的原文或加 role 后重提；不返回 seq/ref/id 选择候选，不默取 first/latest，不提供 occurrence。没有原文命中时明确说明匹配 basis，不以日志扫描、模糊匹配或猜测性重映射兜底。

唯一定位仍须通过保护、完整工具配对和区间校验。倒序、重叠、相邻、重复或其他非法选区均拒绝；不为修复工具配对或绕开保护自动扩界。

### 提交时同步采样，保留预检后的目标身份

模型无需提交 `snapshot_ref`，也无需先调用新的采样工具。宿主在本次 `context_compress` 中通过 Query `captureSession` 同步取得当前调用会话的当前 Surface，在同一次 capture 内固定内部 cut、派生文本和全部区间的解析结果，再整体预检。borrowed reader 不跨 callback 保留；执行所需目标资料由宿主保存。

本协议没有“取图前 baseline freshness”：文本解析只承诺定位本次采样中的当前节点，不识别模型昔日见到的旧节点。旧正文被摘要替换后，其中同一句话若唯一命中当前摘要，候选就是该摘要节点，仍须通过保护与配对检查；不能据此认定旧原节点仍存活，也不增加旧文本 hash 或跨调用识别机制。

内部 seq 继续作为事件和节点实现身份，用于预检后的目标确认，不作为模型选区输入。完整目标在预检中固定，包括有序节点、不可变事件、派生消息、计量和保护信息；执行前沿用原协议重验目标是否仍存活、顺序与内容是否一致、保护和工具配对是否满足。目标变化时停止，不重新以同一句文本匹配另一个节点继续执行；普通尾部追加或选区外变化不新增全局 generation freshness 门槛，原生单项事务自身的校验仍生效。

### 保留 ACP 提交与生命周期

以下决策不因定位方式改变：

- 模型在独立 assistant 响应中直接调用一次 `context_compress`，使用 native/both；可有 reasoning，不带其他工具或任务正文，不经 run_code/PTC。
- 当前调用作者须已正常落档；全批目标、摘要预算与工具调用身份先整体预检，预检失败全批拒绝。
- 保护当前 system/developer、当前 Step、最新任务输入及承载它的存活 checkpoint、全部存活 `form:instructions`；来源判断及 carrier 保护延续 ACP ADR 0001。
- 按初始 Surface 从尾到头逐项使用原生事务；首个执行失败或目标变化停止，已提交项保留，不 rollback。重提时按当时当前 Surface 重新定位，只选失败或未执行项。
- finalizeContent 保留取消、部分成功和 replacement 已写入后的真实提交事实；全批成功且最终工具结果正常时，按原 pre-step 资格检查隐藏调用与结果工具对，以有界短确认替换。失败、部分成功、取消或清理条件不满足时保留原工具对，原始 Log 和回放关系保留。
- 摘要由当前工作模型撰写，保留继续工作所需结论、精确名称与路径、修改与验证证据、失败、未解决项、约束、不确定性和回读入口；不增加区段摘要生成或额外 LLM。

### 提醒与历史回读

压力提醒只提供压力信息、计量依据和简短行动建议：选择已处理的旧内容，用独特原文端点提交摘要，必要时回读历史。取消粗地图、ID 候选、locator 和地图预算；提醒本身及包装仍受有界输出预算控制。

保留 `measurement.totalTokens`、baseline/delta 的计量依据、原生 H 与提醒 S／复位 R 的关系，以及每段持续高压只提醒一次、落档确认、恢复和清理不重置提醒的机制。提醒不增加付费请求，也不改变原生 pruner、自动摘要和 overflow 兜底。

正常历史回读仍使用现有 session/event read、search、trace 工具。search 仍是索引 FTS token search，不变成字面定位器，索引不可用时不偷偷 scan fallback。压缩入口在明确的当前 Surface capture 内解析文本，不扫描历史 Log，不替代历史检索。

## 理由与替代方案

### 定位与导航的取舍

采用 literal 短原文（包括普通关键词）与可选 role：模型已有独特原文时可以直接提交，宿主以节点级唯一性给出确定的接受或拒绝。文本端点可能比 ID 更长，也可能因重复、复制不准或无 text 而失败；选择它是为了去掉必经地图和第二套定位接口，不是认定它在所有任务中都更便宜。

| 方案 | 价值 | 当前未采用的原因 |
|---|---|---|
| 保留完整地图 | 集中展示当前 Surface 结构、来源、节点体量和回读入口，重复文本或无 text 节点也可定位 | 必须先取得定位结果并维护地图字段、预览和消费者。地图可以按需获取，并非天然每步注入；这里舍弃的是前置调用及结果成本和独立导航接口 |
| 紧凑短地图、去除 DTO 冗余 | 去掉重复 seq、locator、计数和诊断，降低单次输出体量；短 range 表仍便于定位 | 缩短结果不能消除先取图再提交的流程，仍需范围引用与刷新协议。采用直接原文定位，不另保留一套精简地图 |
| 输入／活动分段加确定性预览 | 按真实输入、checkpoint、Turn/Step 与体量组织历史；输入摘录、工具／对象指纹、首尾原文、稀疏时间线和多类信号覆盖可帮助识别区段，无需 LLM | 活动分段本身有用，但展示分组不是合法压缩切点，机械摘录也可能漏掉中段约束。取消地图后无需为这些预览另养导航器；详细内容继续交给现有回读工具 |
| 按需 lookup 后返回 ref/ID | 不常驻注入标记，也能对重复文本或难以记住原文的节点给出明确候选 | 增加一次查找及第二套模型选择接口，还需候选与当前节点的绑定、失效处理。当前不考虑 ID 锚点，不以此作为文本歧义 fallback |
| 每消息内联 ID | 模型读原文时即可看到可引用身份，无需独立地图 | 每条消息增加输入开销，同一消息的多个工具部分还可能重复标签；要求明确持久化和替换后的身份语义。当前不采用常驻标记，不用它换取无 text 场景的覆盖 |
| 稀疏活动／完成工具 batch mark | 比每消息 ID 少，能标出工作单元边界，适合粗粒度定位 | 仍需可见标记、活动与当前节点的对应；完成 batch、无工具步骤、取消及部分压缩后的边界不能仅凭一个结束标签推断。当前直接用原文选区，不维护这套导航身份 |
| regex | 可用模式表达编号、行首或部分文本变化 | 增加方言、转义和匹配范围语义，且不能自动解决不同节点的重复。普通关键词已经可用 literal substring 表达，当前不开放 regex 或跨节点捕获 DSL |
| occurrence 与 fuzzy | occurrence 可按顺序挑选重复节点，fuzzy 可容忍复制偏差 | 前者要求模型准确计数且位置随替换变化，后者把明确拒绝变为近似选择。保留独立唯一匹配，让模型换原文或加 role，不猜 first/latest |
| 代表性打分预览 | 可在有限预算内挑选差异较大的消息，减少模板重复 | 需要权重与选择规则，也可能漏掉重要约束；当前不保留地图，未有理由为其增加独立打分导航层 |
| 额外 LLM 区段标题或摘要 | 可生成更易读的语义线索 | 增加生成调用、输入输出与延迟，还需维护线索和实际节点的对应；它不是确定性地图原设计的必要部分。摘要由当前工作模型在压缩提交中撰写，不另设标题或区段摘要模型 |

### 稀疏 mark 的放置方式

即使选择稀疏标记，也需区分“可记录的宿主内容”和“修改模型原始产物”。当前不采用 mark，但各放置方式未采用的理由不同：

- **独立 host context。** 可用正常落档的宿主消息或按需工具结果提供活动索引，来源清楚、无需修改原文；代价是新增消息包装和节点，且旧索引会失效。它是合法备选，但仍保留第二套导航接口。
- **工具结果 post-execute 装饰。** 可在最终结果的独立 text block 加标记，沿正常工具结果落档；但会改变 model-facing 结果内容，影响只接受纯 JSON 文本的消费者，并需处理工具自身 finalizer、外层 batch 与取消等覆盖差异。不能假定一个通用 listener 能为所有活动补齐末尾 mark。
- **content-only tool/result replacement。** 可用合法的已记录单节点 replacement 保留原始结果、只改当前派生正文；它不是篡改原模型输出。但每次增加 replacement 和日志记录，使原节点身份失效并可能影响缓存，作为导航标记比前两者更重，当前不采用。
- **直接修改模型 output 或 tool arguments。** 不作为合法放置路径：不能把宿主标记伪装成模型原始产物；在 arguments JSON 后追加 tag 还会破坏 JSON，加入额外字段也会改变原调用参数。合法宿主消息或工具结果装饰与这种直接改写必须分开。

### 宿主策略与模型选区的边界

宿主自动压缩旧 prefix、pruner 与 overflow 继续作为容量兜底：即使模型忽略提醒、文本定位失败或单步增量跨过阈值，原生路径仍按其规则处理压力。但自动选择旧前缀不能替代工作模型选择任意多个非相邻区间、保留中间原文的能力；ACP 因此保留模型直接选区及预写摘要。

自动扩界、按旧文本自动重试会改变模型提交的完整目标；宿主只验证和提交，失败由模型重新选择。上述未采纳方案是当前设计边界，不表示它们永远不可重新评估，也不为当前接口保留隐式 fallback。

## 后果

已记得独特原文时，模型可以直接提交，不必先获取地图；不再为定位持续注入 mark，也不需要持久文本索引或额外模型调用。文本解析仍须检查本次当前 Surface 的全部匹配节点，不能以截断扫描后发现一个命中冒充唯一性。

重复模板、复制不准确、原文已被替换以及端点没有 text block 的场景可能拒绝；可选 role 也不能保证消除歧义。模型应换独特原文或其他合法完整节点边界；无法表达时保留原文并由原生压力处理兜底，不回退到 ID/map。取消地图也放弃了其模型侧结构和逐段体量浏览能力。

原文端点、歧义诊断、回读、摘要、工具结算和提醒都有成本，历史前缀替换也可能影响缓存。不据此承诺固定 token、延迟或费用节省；本决策取舍是去掉必经地图，接受原文唯一性限制。

## 设计依据

[OpenCode ACP 的固定版本字面替换执行器](https://github.com/tuanhung303/opencode-agent-context-pruning/blob/10039125ffd6ccd16993d436f747afd9013d39e9/lib/strategies/replace.ts)提供由模型首尾原文定位、无匹配或多匹配拒绝的直接先例。它替换单个 text part 内的子串，并按所实现的首尾配对算法计数；本 ADR 只借鉴字面输入和明确拒绝，独立规定跨节点整区间、节点级唯一性及 DSH 保护和原生事务，不照搬其字符阈值或配对算法。
